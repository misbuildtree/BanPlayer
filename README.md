# BangPlayer

가볍고 깔끔한 Windows 동영상 플레이어입니다.

**100% 무료 · 가정용·상업용 모두 사용 가능 · 광고 없음 · 정보 수집 없음**

## 다운로드

오른쪽 **Releases**에서 최신 버전의 `BangPlayer-Setup.zip`을 받으세요.

- 지원: Windows 10 / 11 (64비트)
- 압축을 풀고 `BangPlayer-Setup-1.0.0.exe`를 실행해 설치합니다.
- 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **[추가 정보] → [실행]**을 누르세요.

## 주요 기능

- MP4, MKV, AVI, WMV, MOV, FLV, WebM 등 대부분의 동영상·음악 재생 (코덱 설치 불필요, 하드웨어 가속)
- 이어보기, 폴더 자동 재생목록, 반복·무작위 재생
- 다중 구간 반복 (0.1초 미세 조정, 순차 반복)
- 썸네일·메모가 있는 북마크
- SMI/SRT/ASS 자막, 두 번째 자막, 싱크·스타일 조절
- 음정 보정 배속, 프레임 이동
- 밝기·대비·채도, 회전, 화면 비율, 10밴드 이퀄라이저
- 화면 캡처, 연속 캡처, GIF 만들기

## 라이선스

BangPlayer는 개인·가정·기업·학교 등 어디서든 무료로 사용할 수 있습니다.
원본 그대로 무료 재배포는 가능하지만 판매나 변조 배포는 할 수 없습니다. 전문은 [LICENSE.txt](LICENSE.txt)를 보세요.
